# Auto Map Generator (写真個別マップ自動生成ツール)

写真ファイル（GPS/EXIF情報付き）が保存されたフォルダを指定し、写真ごとに**撮影場所を中心とした個別マップ画像**を一括で自動生成・保存するツールです。

非開発者が直感的に操作できる **GUI画面（Tkinter）** と、開発者やスクリプト連携に最適な **CLI（コマンドライン）** の両方に対応しています。画面で設定したオプションは自動的に保存され、次回起動時にも引き継がれます。

---

## 🖥️ クイックスタート (GUI・非開発者向け)

最もシンプルな起動方法は、フォルダ直下にある **`run.vbs`** をダブルクリックすることです。

### 1. 起動方法
- **`run.vbs` をダブルクリック** (推奨):
  黒いコマンドプロンプト画面を表示させず（背景でサイレント実行）、必要な環境構築 (`uv sync`) から GUI 画面の起動まで全自動で行います。
- **`run.bat` をダブルクリック**:
  コマンドプロンプト画面を表示しながら起動します。進捗ログや同期処理をコンソールで見たい場合に利用してください。

### 2. GUIの基本操作手順
1. **入力写真フォルダの選択**:
   「入力写真フォルダ」の「参照...」ボタンをクリックし、写真（`.jpg`, `.jpeg`, `.tif`, `.heic` など）が保存されているフォルダを選択します。
2. **出力先フォルダの設定 (任意)**:
   省略時は入力フォルダ配下に `map_outputs` フォルダが自動作成されます。
3. **マップオプションの調整 (任意)**:
   画像の幅・高さ(px)、ズームレベル(1〜19)、ピン画像、タイルURLを指定できます。
4. **一括生成の開始**:
   「▶ マップ一括生成を開始」ボタンをクリックすると処理が始まり、プログレスバーと進捗ログエリアに進行状況が表示されます。必要に応じて「■ 中断」ボタンでいつでも停止できます。

> 💡 **設定の自動永続化 (`config.json`)**:
> GUIで設定したフォルダパスや解像度、ズームレベル等は自動的に `config.json` に保存されます。次回起動時には前回の設定状態からすぐに使い始めることができます。

## 🎨 Tkinter GUI 画面の機能と特長

GUI画面 ([app/gui.py](app/gui.py)) は、標準ライブラリの `tkinter` と `ttk` を使用して構築されており、以下の特長を備えています。

- **非依存・未署名警告なし (No Exe)**:
  未署名の Windows `.exe` 化を行わないため、SmartScreen 警告や高額な署名証明書、複雑なストア登録の手間を回避し、Windows 上で安全かつ軽量に動作します。
- **ノンブロッキング非同期処理**:
  地図タイルのダウンロードや合成処理はバックグラウンドスレッド (`threading`) で実行されるため、処理中も画面がフリーズせず滑らかに動作します。
- **進捗のリアルタイム表示**:
  プログレスバーでパーセンテージを確認できるほか、テキストログ領域に処理中のファイル名、検出した緯度・経度、成功/スキップ情報をリアルタイム出力します。
- **安全な中断機能**:
  大量の写真処理中であっても「■ 中断」ボタンを押すことで、現在処理中の枚数で安全に停止できます。

## 🚀 CLI クイックスタート (開発者・コマンドライン向け)

### 1. 準備（依存関係の同期）
```powershell
uv sync
```

### 2. コマンドラインからの GUI 起動
```powershell
uv run python -m app.gui
```
または登録済みのスクリプト名で起動:
```powershell
uv run auto-map-generator-gui
```

### 3. CLIでの一括生成実行
```powershell
uv run main.py -i "C:\Users\jojob\Pictures\Travel2026"
```
または登録済みのスクリプト名で実行:
```powershell
uv run auto-map-generator -i "C:\Users\jojob\Pictures\Travel2026"
```

## ⚙️ パラメータ（GUI項目 / コマンドライン引数）一覧

| GUI項目 | CLI引数 | 短縮 | 既定値 | 説明 |
| :--- | :--- | :--- | :--- | :--- |
| 入力写真フォルダ | `--input-dir` | `-i` | **(必須)** | 対象の写真が保存されているフォルダのパス |
| 出力先フォルダ | `--output-dir` | `-o` | `[入力]/map_outputs` | 生成した地図画像の保存先フォルダ |
| 横幅 (px) | `--width` | `-W` | `800` | 出力する地図画像の横幅 (px) |
| 縦幅 (px) | `--height` | `-H` | `600` | 出力する地図画像の縦幅 (px) |
| ズームレベル | `--zoom` | `-z` | `15` | 地図の拡大倍率・ズームレベル (1〜19) |
| ピン画像 | `--pin-image` | - | `assets/green_pin.png` | 使用するピン画像ファイルのパス (`red_pin.png` や `blue_pin.png` も指定可) |
| タイルURL | `--tile-url` | - | OpenStreetMap | タイル画像のテンプレートURL |

## 🛠️ 主な仕様と特長

1. **Tkinter GUI + 設定永続化**:
   - `config.json` により設定値（入力/出力パス、解像度、ズームレベル等）が自動保存されます。
2. **自動環境構築バッチ**:
   - `run.vbs` または `run.bat` をダブルクリックするだけで、`uv` の自動セットアップ、依存環境の同期、GUIの起動まで全自動で完結します。
3. **しずく型ピンの正確な配置**: 
   - ピン画像の下端中央（先端）が撮影地点の中心座標にぴったり重なるように自動計算されて描画されます。
4. **タイル自動キャッシュ**: 
   - 取得した地図タイルは一時フォルダ (`%TEMP%\auto_map_generator_tiles`) に保存され、再取得がスキップされるため2回目以降の実行や近接場所の写真の処理が高速です。
