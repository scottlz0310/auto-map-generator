# GUI化およびBat起動自動化 計画ドキュメント

## 1. 概要・目的

本プロジェクト（`auto-map-generator`）は、写真のGPS位置情報から個別マップ画像を自動生成するCLIツールとして完成しています。
非開発者を含む幅広いユーザーへの展開を目指し、以下の要件を満たすGUI環境を構築します。

- **exe化を行わない理由**: 未署名実行ファイルに対するWindows Defender / SmartScreen警告の回避、証明書購入・維持コストの回避、ストア登録・自己署名スクリプト等の複雑化の防止。
- **アプローチ方針**: Python標準ライブラリの `tkinter` を使用して軽量かつ安定したGUIを実装し、起動・環境構築は `.bat` ファイルで全自動化します（依存関係・Python実行環境は `uv` を使用）。

---

## 2. 全体構成とアーキテクチャ

### 2.1 コンポーネント構造

```text
auto-map-generator/
├── setup_and_run.bat   # 非開発者向け起動バッチ（uv自動セットアップ＆起動）
├── run_gui.bat         # 2回目以降の高速起動用バッチ
├── pyproject.toml      # 依存関係定義
├── uv.lock             # パッケージバージョン固定
├── main.py             # CLIエントリポイント
├── app/
│   ├── __init__.py
│   ├── core.py         # マップ生成コアロジック（CLI/GUI共通）
│   └── gui.py          # Tkinter GUI実装
└── docs/
    └── gui_plan.md     # 本ドキュメント
```

### 2.2 コアロジックの分離 (リファクタリング方針)
現在の `main.py` に含まれている地図描画・GPS解析処理を `app/core.py` へ分離し、CLI (`main.py`) と GUI (`app/gui.py`) の両方から同一のビジネスロジックを呼び出せる構成に変更します。これにより二重管理を防ぎ、保守性を高めます。

## 3. Batファイル（自動セットアップ＆起動）の設計

非開発者が「バッチファイルをダブルクリックするだけ」で利用を開始できるようにします。

### 3.1 処理フロー (`setup_and_run.bat`)
1. **uvの存在チェック**: システムに `uv` がインストールされているか確認。未導入の場合は `powershell` 経由でスタンドアロン `uv` を自動インストール。
2. **仮想環境および依存関係の同期**: `uv sync` を実行して、`.venv` の構築と `pyproject.toml` に定義されたライブラリ（`Pillow`等）の自動導入。
3. **GUIの起動**: `uv run python app/gui.py` を実行。

---

## 4. GUI機能仕様 (`app/gui.py`)

標準ライブラリ `tkinter` および `ttk` を使用し、シンプルで直感的なUIを提供します。

### 4.1 画面要素・レイアウト
- **入力・出力設定**
  - 入力写真フォルダ選択 (`filedialog.askdirectory`)
  - 出力先フォルダ選択 (デフォルト: 入力フォルダ内の `map_outputs`)
- **マップ設定**
  - 画像サイズ: 横幅 (`width`), 縦幅 (`height`) スピンボックス
  - ズームレベル: `zoom` (1〜19のドロップダウン/スライダー, デフォルト15)
  - ピン画像選択: `green_pin.png`, `red_pin.png`, `blue_pin.png` 等の参照ダイアログ
- **実行制御・進捗表示**
  - 「生成開始」ボタン
  - プログレスバー (`ttk.Progressbar`)
  - 処理ログ出力欄 (`scrolledtext.ScrolledText`)：処理中の写真名、成功/失敗ステータス、現在進捗 (例: `3 / 15 枚処理完了`)

### 4.2 非同期処理（UIフリーズ防止）
- 地図画像のダウンロードおよび画像合成処理は重いため、`threading.Thread` を利用してバックグラウンドで実行します。
- メインUIスレッドのレスポンスを維持し、プログレスバーやログ更新を安全に行います。

## 6. 保守性と今後の留意点

1. **Python / 依存関係の自動追従**: `uv.lock` をコミット・配布に同梱することで、どのPCで実行しても同一バージョンのライブラリ環境が再現されます。
2. **SmartScreen警告の回避**: Windows Defenderは未署名の `.bat` ファイルやスクリプト実行には過度な警告を出さないため、環境のインストールコスト・運用障害を最小化できます。
